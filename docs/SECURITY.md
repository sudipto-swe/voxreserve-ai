# SECURITY & PRIVACY SPECIFICATION

## 1. Authentication & Authorization
- **Passwords**: Salted hashing with `bcrypt` (mitigating long-byte vulnerabilities).
- **Tokens**: JWT signed with `HS256` secret key and configurable expiry.
- **Role-Based Access Control**: Sensitive admin and analytics endpoints require authorized credentials.

## 2. Customer Authority Verification
- Customers can only cancel or modify reservations by presenting the matching phone number used during creation.
- Arbitrary modification of other guests' bookings is strictly rejected.

## 3. SQL Injection & Injection Prevention
- No arbitrary SQL is generated by the LLM.
- All database queries are executed via SQLAlchemy parameterized ORM operations.
- Input models are strictly typed and validated with Pydantic.

## 4. Audio Privacy
- Raw microphone audio streams are processed locally in the user's browser.
- No audio files or raw voice bytes are stored on the server.
